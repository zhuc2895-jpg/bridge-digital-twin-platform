# 01: 可测试的批量摄入与实时状态闭环

**What to build:** 建立可重复运行的自动化测试基座和应用装配接缝；让机器客户端能够通过 JSON 数组或 CSV 文件一次摄入最多 10000 条传感器读数，校验字段，立即更新最新状态，并通过查询与健康检查接口确认结果。数据格式错误时整批拒绝并返回明确的 400 错误，不产生部分写入。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 提供可复现的 Python 依赖清单，一条公开命令可运行后端自动化测试，测试之间使用隔离的应用实例和状态存储。
- [ ] 版本控制忽略 Python 缓存、Node 依赖、构建产物和本地测试产物。
- [ ] JSON 和 CSV 上传均要求 `sensor_id`、`name`、`type`、`value`、`timestamp`；缺少字段、非法类型、未知传感器类型或超过 10000 条时返回 400。
- [ ] 上传成功后返回摄入条数、触发告警数和更新后的传感器数量；`push_live` 参数被接受且默认开启。
- [ ] 最新状态支持查询全部传感器和指定传感器，健康检查返回状态、传感器数量、保留告警数量和仿真器状态。
- [ ] 单批 10000 条数据在标准测试环境中完成摄入和最新状态可见，总耗时不超过 500ms。
- [ ] 覆盖正常上传、两类非法输入、空批次、10000 条边界和 10001 条拒绝的测试。

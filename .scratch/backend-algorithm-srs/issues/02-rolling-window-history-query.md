# 02: 滚动窗口、全量历史与降采样查询

**What to build:** 为每个传感器维护最近 500 条滚动窗口和最多 100000 条按时间可查询的全量历史；机器客户端可以查询最近历史、统计值、全局时间范围，以及指定时间范围并受最大返回点数限制的历史数据。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] 滚动窗口始终只保留最新 500 条，超过后按 FIFO 丢弃最旧读数。
- [ ] 全量历史按时间顺序保存，每个传感器超过 100000 条后只淘汰最旧数据。
- [ ] 最近历史接口支持 1～1440 分钟；统计接口返回均值、最大值、最小值和最新值。
- [ ] 时间范围查询包含边界时间戳，`max_points` 仅接受 10～5000，超过上限时返回恰好 `max_points` 个按时间均匀分布的数据点。
- [ ] 导入 86400 条单传感器数据后，可查询完整时间范围，且范围查询结果与源数据一致。
- [ ] 非法时间范围和非法 `max_points` 返回 400，并通过自动化测试覆盖窗口边界、淘汰边界和降采样结果。

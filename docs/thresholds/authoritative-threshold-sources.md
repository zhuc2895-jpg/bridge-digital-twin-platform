# 权威物理阈值来源与整定参考（Ticket 15 支撑材料）

> 目的：为应变、位移、加速度、温度四类传感器的黄/橙/红阈值提供权威规范依据。
> 注意：国家及行业规范中的阈值多以「设计值倍数」表达（如 0.8×设计值），并非统一的绝对数值；
> 绝对数值必须结合本桥设计文件（设计挠度、设计应变、设计温度）计算确定，并经工程负责人签字确认后方可把 provenance 升级为 authoritative。

## 2. 分级映射

- SJG 148-2024 §8.3.3：特殊事件报警分**黄色 / 橙色 / 红色**；养护检查报警分**一级 / 二级 / 三级**。
- JT/T 1037-2022 表 9：超限分**一级 / 二级 / 三级**（三级最严重）。
- 本平台映射约定：**黄 = 一级（预警），橙 = 二级（超限），红 = 三级（报警/严重超限）**。

## 3. 四类传感器黄/橙/红阈值（规范公式 + 单位）

### 3.1 应变（微应变 µε）

| 级别 | 规范阈值（JT/T 1037-2022 表 9；SJG 148-2024 表 8.3.6「关键截面应变」） |
|------|------|
| 黄（一级） | 超过**历史最大值** |
| 橙（二级） | 超过**设计最不利工况计算值** |
| 红（三级） | 规范未定义应变三级；平台可自定 1.2×设计最不利工况计算值（外推，需签字确认） |

- 单位：µε。规范给出的是相对基准，绝对数值 = 本桥关键截面设计最不利工况计算应变，需查设计文件。

### 3.2 位移（毫米 mm）

主梁挠度（SJG 148-2024 表 8.3.6；JT/T 1037-2022 表 9 中位移类为 0.8×设计值=二级、1.0×=三级）：

| 级别 | 规范阈值 |
|------|------|
| 黄（一级） | 0.8 × 设计挠度值 |
| 橙（二级） | 1.0 × 设计挠度值 |
| 红（三级） | 1.2 × 设计挠度值 |

- 设计值来源：JTG 3362-2018，梁式桥主梁由汽车（不计冲击）与人群频遇组合产生的竖向挠度限值 L/600，悬臂端 L/300。
- 示例（L = 30 m 简支梁）：设计限值 50 mm → 黄 40 mm / 橙 50 mm / 红 60 mm。
- 其他位移（梁端纵向、支座位移、墩顶/塔顶位移、拱顶位移）：同结构（0.8×=一/二级、1.0×=二/三级、1.2×=三级），基准为各自「容许值/设计值」。

### 3.3 加速度（m/s²，10 min 均方根 RMS）

主梁振动 / 涡振（JT/T 1037-2022 表 9；广东省指南、贵州省指南；SJG 148-2024 表 8.3.6）：

| 级别 | 规范阈值 | 换算 |
|------|------|------|
| 黄（一级） | 31.5 cm/s² | 0.315 m/s²（≈ 32 mg） |
| 橙（二级） | 50 cm/s² | 0.50 m/s²（≈ 50 mg） |
| 红（三级） | 80 cm/s² | 0.80 m/s²（≈ 80 mg） |

- 依据：ISO 2631-1 人体舒适度（「稍有不舒适」「比较不舒适」「不舒适」下限）。
- 拉（吊）索振动（SJG 148-2024）：一级 100 mg（≈0.98 m/s²）、二级 300 mg（≈2.94 m/s²）。
- 桥墩船撞/撞击（SJG 148-2024 表 8.3.5 特殊事件）：橙色 10 mg、红色 20 mg。
- MH/T 5088-2025：主梁振动加速度 10 min 均方根 0.5 m/s² 触发一级报警。

### 3.4 温度（°C）

| 级别 | 规范阈值（JT/T 1037-2022 表 9） |
|------|------|
| 黄（一级） | 构件最高温度 / 最低温度 / 最大温差达到 **1.0 × 设计值**；混凝土、钢结构构件温度达到设计值；桥面铺装层温度 > 60 °C 或 < −20 °C |
| 橙（二级） | 最高温度 / 最低温度 / 最大温差达到 **1.2 × 设计值** |
| 红（三级） | 规范未定义温度三级；平台可自定（需签字确认） |

- 设计温度来源：JTG D60-2015（按桥址地区气象资料确定整体温度与梯度温度设计值）。
- 示例（设计温度上限 40 °C）：黄 40 °C / 橙 48 °C（1.2×）；铺装层 > 60 °C 独立触发黄警。

## 4. 结论与落地建议

1. 没有任何一份规范为四类传感器直接给出统一的绝对黄/橙/红数字——**规范给的是「设计值倍数」和分级框架**，绝对值必须由本桥设计文件计算得出。
2. 对仿真/演示平台，可按下述整定（均需工程负责人签字后才能记为 authoritative）：
   - 应变：黄 = 历史最大 ε_hist（µε）；橙 = 设计最不利工况计算应变 ε_d；红 = 1.2 ε_d
   - 位移：黄 = 0.8 d_d；橙 = 1.0 d_d；红 = 1.2 d_d（d_d = 设计挠度限值，mm）
   - 加速度：黄 = 0.315；橙 = 0.50；红 = 0.80（m/s²，10 min RMS）
   - 温度：黄 = 设计温度 T_d；橙 = 1.2 T_d；铺装层 > 60 °C 触发黄警（°C）
3. 满足 ADR-0011 的 authoritative 要求后，将数值 + provenance（document/version/section/effective date/approver/scope/units）写入单一 JSON，经 `BRIDGE_THRESHOLD_PROFILE_PATH` 导入。

本桥（L = 120 m 钢箱梁斜拉桥）的逐测点推导、单位与 S01–S08 映射见 `docs/thresholds/sensor-baseline-and-mapping.md`；当前可运行档案为 `config/bridge-threshold-profile.json`，状态为 `provisional`（`code-derived-v1-pending-signoff`）。

# S01–S08 测点设计基准与阈值映射（竞赛基线，toB 预留审批）

> 本文件给出各测点的设计基准推导。凡标注「拟定」的数值为竞赛演示整定值；后续 toB 部署可按第 4 节的审批接口把 `config/bridge-threshold-profile.json` 的 provenance 升级为 authoritative（ADR-0011）。

## 1. 桥梁基准假定（拟定）

- 桥型：大跨径斜拉桥（与仿真布局一致）
- 主跨：L = 120 m（与前端可视化一致）
- 主梁：钢箱梁（Q345q 系列）；索塔：C50 混凝土
- 气候分区：温热地区

## 2. 各测点设计基准

### S05 主跨跨中挠度（mm）

- 依据：JTG/T 3365-01-2020《公路斜拉桥设计规范》§7.2.5：钢梁主梁在汽车荷载（不计冲击力）作用下最大竖向挠度 f ≤ L/400（f 取正负挠度绝对值之和）。
- 设计挠度 d_d = 120 000 / 400 = **300 mm**
- 分级（JT/T 1037-2022 表 9；SJG 148-2024 表 8.3.6）：黄 0.8× = 240｜橙 1.0× = 300｜红 1.2× = 360 mm
- 备选：若主梁为混凝土箱梁，限值为 L/500 → d_d = 240 mm（黄 192 / 橙 240 / 红 288）；若按梁式桥 JTG 3362-2018 §6.5.3 取 L/600 → 200 mm（黄 160 / 橙 200 / 红 240）。

### S03 索塔顶部位移（mm）

- 规范只给分级倍数（0.8×/1.0×/1.2× 设计值），塔顶位移容许值须由本桥设计文件（最不利工况有限元）给出，无统一规范值。
- 拟定容许值：**50 mm**（按塔高约 50 m 的 H/1000 经验量级，演示整定，待签）。
- 黄 40｜橙 50｜红 60 mm。

### S01 / S02 / S06 应变设计基准（µε）

- 分级依据：JT/T 1037-2022 表 9、SJG 148-2024 表 8.3.6「关键截面应变」：一级 = 超历史最大值；二级 = 超设计最不利工况计算值；三级规范未定义（平台外推 1.2 ε_d，待签）。
- 设计最不利工况计算应变 ε_d（拟定）：
  - S01 主跨跨中（钢箱梁）：ε_d = **1200 µε**（Q345q 抗拉压设计值 f_d ≈ 275 MPa、E = 206 000 MPa 对应约 1335 µε，按最不利组合计算取 1200）
  - S02 主跨 1/4 截面：ε_d = **900 µε**（按跨中 0.75 折减）
  - S06 索塔底部（C50 混凝土）：ε_d = **650 µε**（C50 f_cd = 22.4 MPa / E_c = 34 500 MPa ≈ 649 µε）
- 阈值（黄暂以 0.8 ε_d 代理「历史最大值」，待积累监测历史后替换为实测历史最大）：

| 测点 | ε_d | 黄 | 橙 | 红（1.2 ε_d，外推） |
|---|---|---|---|---|
| S01 | 1200 | 960 | 1200 | 1440 |
| S02 | 900 | 720 | 900 | 1080 |
| S06 | 650 | 520 | 650 | 780 |

### S04 / S07 拉索加速度（m/s²，10 min 均方根）

- 依据：SJG 148-2024 表 8.3.6「拉（吊）索振动加速度」：一级 100 mg、二级 300 mg（mg = 10⁻³ g）。
- 换算：100 mg ≈ 0.98 m/s²；300 mg ≈ 2.94 m/s²。
- 三级映射（规范未定义拉索三级，平台外推 1.5 × 300 mg = 450 mg，待签）：
  - 黄 = 0.98｜橙 = 2.94｜红 = 4.41 m/s²
- 注意：0.315 / 0.50 / 0.80 m/s² 是**主梁涡振**阈值（JT/T 1037-2022 表 9 / ISO 2631-1），适用于桥面加速度计，不直接适用于 S04/S07 拉索加速度计；类型级 acceleration 档仍保留该值备用。

### S08 桥面温度（°C）

- 依据：JTG D60-2015 §4.3.12 表 4.3.12-2 有效温度标准值：钢桥面板钢桥最高 **46 °C**（各气候分区相同）；最低按分区（温热 −9 °C，昆明/南宁/广州/福州 −3 °C）。
- JT/T 1037-2022 表 9：构件温度达 1.0× 设计值一级、1.2× 二级；桥面铺装层 >60 °C 或 <−20 °C 报警。
- 设计温度 T_d（最高）= **46 °C** → 黄 46｜橙 55.2（1.2×）｜红 60（铺装层报警限值）°C
- 补充：梯度温度基数 T₁（50 mm 沥青铺装）= 20 °C、（100 mm）= 14 °C、（混凝土铺装）= 25 °C，如需监测「最大温差」按 1.0×/1.2× T₁ 设置。
- **当前边界**：S08 只表达高温上限；低温（如铺装层 < −20 °C）和梯度温差需要独立的双向/差值阈值模型，尚未纳入本版映射。现有阈值检查对读数取绝对值，因此负温度会落入高温档，不能宣称覆盖低温报警。

## 4. 竞赛基线定位与 toB 审批接口（预留）

- 本项目是大学生竞赛作品，当前没有工程负责人签字流程；本表数值作为**竞赛演示与算法验收基线**使用。
- `config/bridge-threshold-profile.json` 保持 `status: provisional`（`competition-design-basis-v1`），运行时不会把它宣称为正式限值。
- 面向后续 toB 部署时，审批接口已预留：在同一 JSON 的 `provenance` 中填写 `approved_by`（姓名/职称）、`effective_date`（ISO `YYYY-MM-DD`），并把 `status` 改为 `authoritative`；数值和代码无需改动。
- 建议 toB 前端/网关以 `provenance.authoritative == true` 作为“可用于生产决策”的开关；`false` 时明确展示为竞赛/演示基线。
